- **The map in the archive.** The Aschers' *Databook II* introduction (scanned at
  [Cornell](https://courses.cit.cornell.edu/quipu/data/intro-2.pdf), read page by page by
  eye) gives the key: ISCC-NBS level-3 colour names, written as "single or double letter
  mneumonics", with `-` barber pole, `:` mottled, `/` end-to-end, lower ISCC number first.
  **Table 5** lists 63 mnemonics with their ISCC numbers. Every one lands on exactly one
  OKR `ascher_color_dc` code with the same ISCC number: 53 identical tokens, and 10 that
  differ only by letter O vs digit zero (`OB`→`0B`, `DO`→`D0`, …). The only OKR code that
  Ascher did not define is `PK`, "unknown Urton color".
- **The Field Guide.** KFG uses the same "65 Brezine/Ascher colors" (the chart shows the same
  64 codes). Its cleaning code recodes some strings (`BY`→`YB`, a bare `-`→`PK`), and its `%`
  means "Striped cord" where OKR's `%` means "con elemento" (Pereyra). I logged these as
  descriptive conflicts, not gate changes.
- **Urton and Pereyra.** No colour dictionary of their own was retrievable. The archived
  Harvard KDP pages say the tables "mimic the layout … first invented by the Aschers", and
  UR001 prints `Color: B-W`. Pereyra's books are print-only. Both → `source_missing` for
  their own dictionary, `okr_codebook_only` for ingestion.
- **Census.** 56 306 colour rows, 1 063 distinct `FULL_COLOR` strings (983 contain an
  operator), 64 component tokens, **64/64 in the OKR dictionary**. Every (recorder, token)
  unit is `same_dictionary` (196 of 196). Planted fixture 13/13; `W`/`AB` control `schema_ok`.
- **The pairs.** Fully usable fraction of coloured level-1 pendants: KH0097 0.997 (one empty
  colour string), KH0586 1.000, KH0192 1.000, KH0470 1.000, KH0469 1.000. All three pairs are
  **`co_mappable`** (threshold 50 %).

Field reading: the three recorders' codes live in one Ascher vocabulary in OKR, so a later
cycle *may* compare them. What the archive does not give us is how Urton or Pereyra chose
a code for a given fibre, so recorder effects stay a named confound. This is a prerequisite,
not a discovery, and nothing here reads a khipu.
