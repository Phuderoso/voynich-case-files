# Caderno de campo · K005 · 5 Nov 2026

Tonight's question crosses between khipus: do two different khipus share long runs of identical numbers, more
than chance would give? I wrote down the test first. The score was the information in the best shared run. The
null shuffled each khipu on its own. The threshold was the maximum over all 104 196 pairs, so a flagged pair
holds up against every other pair.

Five pairs crossed the line. The loudest is a ghost: KH0140 and KH0483 are the same Berlin khipu from Pachacamac,
recorded twice (14 of 15 pendants identical). The Khipu Field Guide knows this, but the OKR database doesn't flag
it as a duplicate and gives two different museum numbers. The second, a Göteborg khipu that shares 28 values with
the famous Lima khipu AS038, is already listed as "similar" in the Field Guide. One pair is a Puruchuco pair of the
kind Urton and Brezine described. One is my own null fooling me: two khipus that each hold a long run of 10s. The
shuffle breaks runs, so the pair looks rare. I'm keeping it in the table with that label.

The honest limit: my trowel only finds long shared runs. A planted 6-cord copy is recovered just 11% of the time,
so I can't say anything about short matches yet.

Outreach: a data-quality note to the OKR about the unflagged double recording is drafted but not yet submitted (status in the README outreach log).
