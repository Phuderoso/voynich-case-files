# Expedition 2 · Inka khipu

A parallel dig to the Voynich trench: exact, test-first analysis of Inka khipus from the
[Open Khipu Repository](https://github.com/khipulab/open-khipu-repository) (OKR). Why khipu: see [TRIAGE.md](../TRIAGE.md).

Method is the same as the main repo: pre-register hypothesis, metric and decision rule; calibrate every null;
plant controls; correct for multiple comparisons; say "not testable" when power is low; publish negatives.
**No decipherment is claimed.**

> **Data-source notice (11 Nov 2026).** Every result K001–K067 below was computed on the historical OKR `khipu.db` @ `4039ca5`.
> On advice from Ashok Khosla (creator of the Khipu Field Guide, [OKR #3](https://github.com/khipulab/open-khipu-repository/issues/3)),
> the expedition moved to the curated **Khipu Field Guide (KFG)** Excel data in [K068](case-file/K068-kfg-migration-crosswalk.md).
> All earlier results are **under KFG re-audit**, one per run, pre-registered; see the *OKR vs KFG replication* table and line 9.
