## Gates
- **G0 / fixture** (passed, above): hashes, universe == K069, list presence. **A0** (passed, above): exact OKR rebuild of K053.
- **G1 FPR** (per arm, per detector): one shuffle of each khipu treated as real, K = 1 000; rate of p ≤ 0.05 must be **≤ 0.05**. Fail → that scan's
  labels are **NOT TESTABLE**. BH flags on the calibration p's reported.
- **G2 power, spec A** (K002/K053): two planted targets = sum of the next 3 pendants (all non-R5 in arm M) on a shuffle of each khipu with ≥ 20 pendants;
  rate of p ≤ 0.05 must be **≥ 0.50**. Fail → drops are labelled **NOT TESTABLE (underpowered drop)**, never CHANGED.

## Decision rules (per published name)
- **U-D2 / U-D5:** each K002 (16) / K003 (20) BH name is **REPLICATED** if BH-significant on KFG, **CHANGED** if not (gates passing), NOT TESTABLE if

- **M-D2 / M-D5:** each K053 name keeps its OKR fate (survives = BH, no longer established = not BH) → **REPLICATED**; a different fate → **CHANGED**.
- **Correction rule:** a CHANGED label with both gates passing means the OKR-era statement does not hold on KFG; it is published as a clearly labelled
  correction in the K002/K003/K053 coverage rows and the replication table. Not a decipherment claim in either direction; same-archive re-curation,
  not an independent replication.
