## 4. Protocol: LLM reconstruction with blind controls (proposed family F-LLM)
1. **Pre-register** (commit before run): model+version, prompt (frozen), temperature, decoding budget, scoring metric, decision rule.
2. **Control set** (N≥30 items, hidden answers stored hashed in repo, revealed after scoring):
   - Real plaintexts (Latin herbal, medieval Italian, Occitan, German, Hebrew/Arabic translit., Nahuatl/synthetic conlang) of Voynich-like length.
   - Transformed by: (a) mono-substitution into EVA glyph set; (b) + intra-word anagram (Hauer–Kondrak); (c) verbose cipher (1 letter → 1–3 glyphs); (d) word-class nomenclator; (e) abjad (vowels dropped).
   - **Negatives** (no answer exists): Timm–Schinner generator output, shuffled Voynich (words/within-word/lines), human gibberish, Rugg table output, random EVA with Voynich h1.
   - Decoys: same text shown twice under different keys (consistency check).
3. **Blinding**: the LLM gets items in random order with identical framing ("this may or may not contain a message"), never told the language set. Voynich passages interleaved as just more items.
4. **Scoring**: per item, chrF / character edit distance and word-accuracy vs ground truth; for negatives, a "claimed-meaning rate" and an independent judge model scoring fluency of output. Key derived metric: **discrimination AUC** between positives and negatives using the model's own confidence + output fluency. Also cross-run stability (3 seeds) and cross-key consistency.
5. **Decision rule**: a reading of a Voynich passage is reportable only if (i) control recovery chrF exceeds a pre-set threshold for the matched cipher class, (ii) negative false-claim rate < 5%, (iii) Voynich output fluency exceeds the 95th percentile of negatives, (iv) stable across seeds and across disjoint folios. Otherwise publish as negative/"not testable".
6. **Multiple comparisons**: count every prompt/model/class tried; Holm or permutation-based family-wise correction.
7. Respect singulion finding: sample passages within a single page/bifolium, never across current page adjacency.
