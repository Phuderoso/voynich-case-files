## Method
- **Independent implementation** (`scripts/v1e.c`), written from the PREREG219 text. col1e.c was read once for conventions
  (grid, COL/ROW, dir, model A/B, AZ/KRYPTOS index, Vig vs Beaufort key sign); its code was not reused. Differences:
  Heap's algorithm over the read order (instead of lexicographic over read ranks with a fixed first column), excess computed by

  by mean log10 quadgram over every 4-gram of known letters (`qg.bin`, float32 26^4, same layout as tools/cycle124/score_surv.py)

- Nulls regenerated by `random.Random(seed).shuffle(list(K4))`, seeds 209234–209241 (`scripts/mknulls.py`); null1_124 regenerated
  by origin's `tools/cycle124/plant.py`.
